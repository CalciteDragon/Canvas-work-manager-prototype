# The overhaul stops below 15 open S2 records

**Question**

How many open S2 records can remain at the end of the overhaul?

**Options tested**

Set 15 as an exclusive ceiling, choose another ceiling, or defer the decision.

**What we learned**

The comb counted 117 open S2 records, including 14 scaffolding records the user kept open.

**Current decision**

User decision, 2026-11-26, [Slice 82 Gate 3](../roadmap/70-ui-ux/comb-82/gate3.md#gate-3-answers).

Set the stop rule to **fewer than 15 open S2 records**, counting the 14 open-by-decision records. A later gate may explicitly revisit the threshold.

**Confidence**

The user approved this decision at Gate 3. The comb measurements remain the evidence for that gate.

**Revisit when**

A later gate explicitly revisits the number, for example if the scaffolding decision changes.
