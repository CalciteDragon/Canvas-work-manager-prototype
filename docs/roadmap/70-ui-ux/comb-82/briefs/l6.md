All 194 matrix cells in `apps/e2e/ux-output/37dd16e2303e7d8968905de74767710d6b02b85c/` (`index.json` lists them: six seeds, both themes, 1440/1024/375 as the

## Your lens: copy and vocabulary

Every visible word, and every accessible name in `.aria.yml`: labels, buttons, menu items, headings,
empty-state and error sentences, confirmations, toasts, tooltips you can see, dates and times, counts,
capitalisation. Is the product's vocabulary (project, workstream, page, section, shortcut, task list,
archive, reflections, agent) used for one thing each, everywhere? Do internal ids, enum values, raw
error codes or developer wording reach a user? Does an accessible name match what is shown? Is the same
action named the same way in different places? Is a sentence clear to someone who has never used the
product? Quote the exact text in `actual`.
