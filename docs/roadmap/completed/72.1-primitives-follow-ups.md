# Slice 72.1 — Primitives follow-ups

## Goal

Close slice 72's three open questions: ghost text buttons get a faint outline at rest, the token
lint checks every `style` attribute written in a TypeScript string (interpolations included), and
the stdio test timeouts grow with how many child processes each case starts.

## Spec sections

§21 (primitives built from tokens; no literals in component styles), §69 (verification you can
trust), §77 (tests change with intent), §78 (the answered question becomes a decision entry).

## Build

- **Ghost outline (user answer, 2026-10-15).** `.button--ghost` gets a resting edge from a new
  `--control-ghost-edge: var(--color-border)`, the faintest line the system has (10 % alpha in
  both themes), and `--control-secondary-edge-hover` on hover. Ghost keeps its transparent fill,
  so it differs from secondary by fill, not by edge. Icon buttons and tools stay borderless at
  rest (principle 5: chrome is quiet). The edge's composite contrast over a sheet and a pane is
  measured in both themes and reported in the decision (the contrast amendment reports, it does
  not gate).
- **Token lint.** Today `checkTypeScript` reads only `styles:` and `template:` properties, and an
  interpolation becomes `EXPR`. After this slice:
  - every string or template literal in a `.ts` file that contains a `style` attribute or a
    `<style>` block is checked as markup, wherever it sits (a `componentWrapperDecorator`
    callback included);
  - an interpolation inside a `style` attribute is resolved to its module-scope string `const`
    and checked; one it cannot resolve fails as `unresolved-style`;
  - a `style` attribute that contains the other quote kind is checked, not skipped.

  The live miss this exposes, `project-page-navigation.stories.ts:62` (`height: 24rem`), is fixed
  with a viewport height. Interpolations inside `styles:` blocks and `[style.x]` bindings keep
  today's behaviour (non-goals).
- **Stdio flake.** The rollback case hit its 20 s limit once in the full suite and twice alone
  (slice 72, Stage A), while starting three `tsx` children. Measured on 2026-10-15: one cold child
  start took 3.2 s and a warm one 0.95 s; the three-child cases take 5.3–6.1 s alone. Each timeout
  becomes `CASE_BASE + children × CHILD_BUDGET`, with both 15 s: 30 s for one child, 60 s for
  three. No timeout shrinks (the old maximum was 30 s).

## Done when

The Lab and the product show ghost buttons with a visible faint edge in both themes, at 1440 and
at 375, while icon buttons and tools stay borderless. `expect-failure.mjs` proves the three new lint
holes fire and the controls stay clean. `stdio.test.ts` passes inside the full `pnpm test`.

## Do not

- Change secondary, primary or danger buttons, icon buttons or tools.
- Reach a 3:1 boundary for ghost. The edge is a hint, not a control boundary (principle 2 keeps
  3:1 for inputs). Contrast stays reported, not gated.
- Rewrite the stdio tests' assertions, or add retries.
- Widen the lint beyond styling positions.

## Boundaries touched

- **No literals in component styles.** The new edge is a token in `_tokens.scss`; `_controls.scss`
  only references it. The lint change makes this boundary stricter, not looser.
- **Components never paint primitives.** No component file changes.
- No domain, contracts, host runtime, gateway or MCP tool code changes; the stdio change is
  test-only.

## Explicit non-goals

- A faint edge on icon buttons or tools, or any change to secondary.
- Resolving imported or computed style strings in the lint. They fail as `unresolved-style`,
  which is the point.
- Interpolations inside `styles:` blocks (still `EXPR`) and inside `[style.x]` bindings.
- Speeding up `tsx` child start-up, or merging stdio cases to start fewer children.

- None. The user answered the ghost question and asked for the other two to be addressed now.

  substantive ones were checked against the code, and all held.

  - **Ghost value.** "From `--color-border`" was ambiguous, because secondary's edge already is
    `--color-border`. The token is named, ghost differs from secondary by fill, the e2e checks the
    fill, and the edge's contrast is reported.
  - **Minor.**

    - Acceptance 1 is observable through `EXPECTED`.
    - A 375 check of the navigation toggle is added, and Storybook is dropped from Done when.

## Outcome

**Deliverables.**
- **Ghost outline.** [`_controls.scss`](../../../apps/web/src/styles/_controls.scss) gives
  `.button--ghost` the new `--control-ghost-edge` from
  [`_tokens.scss`](../../../apps/web/src/styles/_tokens.scss) at rest, and secondary's edge on
  hover. Its fill stays transparent. Icon buttons and tools are unchanged.
  [`primitives.spec.ts`](../../../apps/e2e/primitives.spec.ts) pins this in both themes. It failed
  on the ghost edge first, then passed with the other three cases (4 of 4).
- **Ghost in use.** On busy-week through the e2e rig's own data file, the Markdown Edit and
  More's Clear and Open archive read as buttons in both themes at 1440. The 375 navigation toggle
  shows its edge in both themes. The measured edge contrast against its plane is 1.33–1.36:1 dark
  and 1.23–1.24:1 light, reported in the
  [decision](../../decisions/2026-10-ghost-buttons-have-a-faint-resting-edge.md).
- **Token lint.** [`check-design-tokens.mjs`](../../../apps/web/scripts/check-design-tokens.mjs)
  reads every non-`styles:` string in a `.ts` file as markup. A `${…}` in a `style` attribute or
  a `<style>` block resolves to an unshadowed module-scope string `const`, or fails as
  `unresolved-style`. A `style` attribute holding the other quote kind is no longer skipped. The
  self-test pins six new entries. The wider scan found one live miss,
  `project-page-navigation.stories.ts:62` (`height: 24rem`), now `60vh`.
- **Stdio timeouts.** [`stdio.test.ts`](../../../apps/prototype-host/mcp/stdio.test.ts) passes
  `budget(children)`: 15 s plus 15 s per `tsx` child, so 30 s or 60 s. No timeout shrank.
- **Checks.**
  - `pnpm test` passed twice in a row, all seven packages green.
  - `pnpm lint` passes with `docs:check`.

**Deliberate choices.**
- **Ghost's edge equals secondary's edge.** It is `--color-border`, the faintest line the system
  has, and ghost differs from secondary by fill alone. A fainter custom alpha was rejected: at
  10 % the edge already measures only 1.2–1.4:1.
- **Icon buttons and tools stay borderless**, under principle 5.
- **Unresolvable style values fail, not pass.** A lint that cannot read a value cannot vouch
  for it, and the stories already use resolvable consts.
- **The timeouts guard against a hang, not slowness.** They grow with the work a case starts,
  rather than adding retries.

**Deviations from the plan.**
- **The domain import-lint timeout was not planned.** `packages/domain/src/import-lint.test.ts`
  failed once in the first full `pnpm test`: one case started three Node scanners (one only to
  build an assertion message) and ran past vitest's 5 s default. It now scans once per check and
  allows 15 s. `time-lint.test.ts` spawns the same way but has not failed, so it was left alone.
- **The diff review added two false negatives to the lint fix:** shadowed names and `<style>`
  interpolations (Revisions).
- **No pixel measurement at 375.** The phone toggle starts at x = 0, so the pixel sampler could
  not measure its edge. The screenshot is the evidence there.
- **`web/what.md` needed no change.**

**Deferred.**
- `time-lint.test.ts`'s default 5 s timeout, if it ever flakes.
- Lint line numbers after multi-line consts.
- Unresolved `[style.x]` bindings.

**Open questions.**
- None from the user's three. The edge may add noise where ghost buttons repeat in rows. Slices
  5 and 6 own those surfaces and should look.
